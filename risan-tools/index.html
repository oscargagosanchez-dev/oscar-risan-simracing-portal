GUÍA OFICIAL

Resultados LMU → Discord · instalación

La versión pública v2.4 es gratuita y no utiliza licencia, cuenta, suscripción ni servidor de activación.

1. Extrae el ZIP

Descarga el ZIP, pulsa «Extraer todo» y abre la carpeta extraída.

2. Instala y configura

Ejecuta INSTALAR Y CONFIGURAR.bat. El bot intenta localizar Le Mans Ultimate\UserData\Log\Results.

3. Nombre de piloto

Escribe exactamente el nombre que utilizas en Le Mans Ultimate.

4. Configura Discord

Crea un webhook en Ajustes del canal → Integraciones → Webhooks. El Discord de equipo es opcional.

5. Prueba el envío

Envía el mensaje de prueba. Cuando aparezca BOT ACTIVO, la configuración está terminada.

6. Déjalo trabajar

Procesa automáticamente las nuevas carreras *R1.xml, incluidas carreras por equipos y relevos.
