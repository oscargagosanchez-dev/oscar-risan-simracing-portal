Soporte y preguntas frecuentes

Información práctica para instalar y usar las herramientas sin complicarse.

¿Las aplicaciones son gratuitas?

Sí. El objetivo actual es que todas las herramientas de Risan Simracing Tools sean gratuitas. El apoyo mediante donación es siempre opcional.

¿Necesito instalar todas las apps?

No. Cada herramienta es independiente y puedes utilizar solamente las que necesites.

¿Funcionan sin modificar Le Mans Ultimate?

La filosofía del proyecto es trabajar en solo lectura siempre que sea posible, usando resultados, datos públicos, Shared Memory o servicios externos sin inyectar ni alterar LMU.

¿Dónde se publicarán las descargas?

En esta misma web cuando cada build esté preparada y revisada para uso público.

¿Puedo usar dos Discord?

Resultados LMU y Race Alerts contemplan configuraciones con uno o dos destinos de Discord. Team Radio utiliza su propio bot/configuración.

Cómo actualizamos cada app

Un proceso sencillo para no romper lo que ya funciona.

1Build estable

Se cierra una versión funcional en el chat/proyecto de la app.

2Pruebas reales

Se valida en LMU, Discord y el escenario para el que fue diseñada.

3Paquete

Se genera el ZIP final, manual, versión y checksum si procede.

4Actualizar ficha

Se actualizan funciones, capturas, instalación, uso y changelog.

5Activar descarga

Solo cuando la versión esté realmente preparada para usuarios.

Plantilla incluida: PLANTILLA_ACTUALIZACION_APP.txt dentro de la carpeta de la web privada.

Compatibilidad e integraciones

Cómo conviven las herramientas sin crear dependencias innecesarias.

✓
Apps independientes

Puedes instalar únicamente la herramienta que necesites.

✓
Integración opcional

Algunas funciones podrán conectarse con LMU Hub en el futuro sin convertirse en una dependencia obligatoria.

✓
Discord por app

Varias herramientas pueden usar Discord, pero cada una mantiene su configuración y sus permisos.

✓
Fácil de diagnosticar

Si una app falla, se puede probar por separado sin desmontar el resto del ecosistema.

Objetivo del ecosistema: que puedas usar una sola herramienta o combinarlas todas según tus necesidades, manteniendo siempre la simplicidad y la independencia de cada proyecto.
